🛡️ Cara Kerja Otomatis Failover Kunci AI

Jika kunci utama mencapai batas request per menit (HTTP 429) atau habis kuota harian, sistem langsung mengalihkan penilaian ke kunci cadangan secara instan tanpa mengganggu siswa yang sedang mengumpulkan jawaban.

• Dapatkan kunci tambahan gratis di Google AI Studio.

• Urutkan prioritas (1 = Kunci Utama, 2 = Cadangan Pertama, dst).

🌐 Multilingual & Anti-Cheat Cerdas

  • Bahasa Arab: Paham teks berharakat & gundul, gramatika nahwu/sharaf, toleransi variasi hamzah (أ/إ/آ) & ta marbuthah (ة/ه).
  • Bahasa Inggris: Evaluasi grammar, tenses, reading comprehension, dan essay analitis.
  • Anti-Pengelabuan AI: Kebal terhadap prompt injection atau manipulasi instruksi di akhir jawaban siswa.

Amankan & Pulihkan Database Sistem

Cadangkan seluruh data ulangan dan nilai siswa ke komputer lokal, atau pulihkan data saat server cloud di-deploy ulang.

📥

Amankan / Cadangkan Database (Backup)

Unduh salinan lengkap database SQLite (.sqlite) yang memuat:

  • Seluruh akun guru & password
  • Daftar kelas & data siswa
  • Daftar ulangan, bank soal, & kunci jawaban
  • Seluruh lembar jawaban siswa & riwayat nilai AI
  • Daftar API Key Gemini yang tersimpan
💡 Tips Praktis: Unduh cadangan database ini sebelum Anda melakukan Re-deploy atau update cloud container agar data nilai tidak hilang.
📤

Pulihkan Database (Restore)

Pulihkan seluruh data dari file cadangan sebelumnya jika Anda baru saja memasang server baru atau melakukan build ulang cloud container.

⚠️ Perhatian Keamanan

Proses pemulihan akan menimpa data yang sedang berjalan dengan isi dari file cadangan. Pastikan file yang dipilih adalah file backup yang benar.
